# Stack-notes — Python (the reference stack)

Written 2026-10-01 from the contract; no field report yet. The reference `ingestion_pipeline.py` needs the standard library and Pydantic (https://docs.pydantic.dev/) for the typed models; the real parser, the PII detector and the store are wired behind its three seams. Check current versions and licences at adoption.

- **Parser adapter:** Docling (https://github.com/docling-project/docling) — `DocumentConverter` → `DoclingDocument`, exported as lossless JSON and mapped to `Element`s with page and bounding box from each item's provenance; or Unstructured (https://docs.unstructured.io/) — partitioned elements mapped by type, `Table.metadata.text_as_html` kept as the HTML view, `page_number` and `filename` into the envelope. A heuristic library such as pypdf (https://github.com/py-pdf/pypdf) is the model-free first pass only. `PARSER_VERSION` is read from the installed package, never hard-coded.
- **VLM as a tool:** a function the harness calls on pages below a confidence threshold or on `image` elements, through the repo's one LLM client (`../../llm-api-calls/`); the model id is a placeholder in config, and its output is an `Element` with `confidence` set by the call, never a replacement of the parsed page.
- **PII detection:** Presidio (https://github.com/microsoft/presidio) analyzer behind `find_pii()` for the NER tier, with the reference's checksum and regex classes kept as the first tier; the anonymizer is not used on the index path — the reference's own placeholders and `ReversibleDictionary` are, so the mapping stays outside the store.
- **Reversible dictionary:** a secret store scoped by tenant (the repo's secrets manager or an encrypted table in a separate schema), never a column next to the embeddings; `unmask()` runs only in the reply path and writes an audit line.
- **Store:** Postgres with pgvector (https://github.com/pgvector/pgvector) behind the five store methods, the envelope as columns with `owner` and `tenant` `NOT NULL`, and **RLS policies** on the elements table reading the session identity (Supabase's shape works on any Postgres); LanceDB (https://lancedb.github.io/lancedb/) or another store for single-tenant or local products, with the tenant as a mandatory metadata filter. Upsert keyed on `(tenant, source_id, document_hash)`.
- **Off the request path:** ingestion is a job — Celery (https://docs.celeryq.dev/), a FastAPI background task for small corpora, or a cron over the corpus folder; the job carries the ingestion `Identity`, the corpus manifest carries owner, tenant, region and date per path.
- **Audit report in CI:** `--audit` runs on the corpus folder and `sync_corpus()` refuses to index (`AuditRefused`) when the report is missing, when `AuditReport.is_stale(parser_version)` or when `sources_without_owner` is non-empty (assertion 1, 2); a document with no manifest owner or with a manifest tenant that is not the job's is refused by `tag_owner()`.
- **Erasure:** one job that calls `erase_subject()` on the store, invalidates the answer cache, filters the eval JSONL (`../../evals/eval_harness.py` tasks) and redacts the trace store, then asserts `mentions()` (by tag) and `scan_content()` (by content) are zero in each and that `erased_at` precedes the deadline; the test plants a subject in all four first and writes one derived copy without its tag to see the content scan catch it (assertion 7).
- **Tests:** `tests/test_ingestion.py` reruns the demo's branches against the real adapter on a fixture corpus with a planted item per PII class (assertion 6), two tenants with overlapping content (assertion 8) and a second run asserting zero growth (assertion 5).
- **Pitfall:** a parser upgraded in `requirements` with no re-audit — the report's `parser_version` check is what catches it.
- **Pitfall:** `model_copy(update=...)` on a document whose pages were cached from the old content — derive pages from content (the reference does) or re-create the document.
