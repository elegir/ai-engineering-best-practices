# Stack-notes — PHP / Laravel

Written 2026-10-01 from the contract; no field report yet. The mechanism is an audit report regenerated per parser version, a queued job that parses each document into typed elements, an envelope table with non-null owner and tenant, a scrub step before the insert, an upsert keyed on `(tenant, source_id, document_hash)`, RLS on a shared Postgres, and a deletion job that reaches four stores. Check package versions at adoption.

- **Parsing as a queued job:** one job per document implementing `ShouldQueue`, dispatched by the upload or by a scheduled corpus walk; PHP-FPM never parses inside the request (stack-sensitive point 1). The job carries the ingestion identity (tenant, service user) and reads owner, region and date from the corpus manifest.
- **Parser:** a **Docling-serve sidecar** (https://github.com/docling-project/docling-serve — Docling as an HTTP API) called from the job with the file, returning the lossless JSON that the adapter maps to element rows with page and bounding box; for text-only PDFs where a model-free first pass is enough, a PHP extraction package family such as `spatie/pdf-to-text` (https://packagist.org/packages/spatie/pdf-to-text, wraps poppler's pdftotext) or `smalot/pdfparser` (https://packagist.org/packages/smalot/pdfparser) — heuristic, so tables and scans still go to the sidecar.
- **Envelope as an Eloquent model** (`elements` table: `source_id`, `filename`, `title`, `page`, `element_type`, `content_hash`, `document_hash`, `owner`, `tenant`, `sensitivity`, `region`, `ingested_at`, `parser_version`, `bbox` JSON, `confidence`, `markdown`, `html`, `embedding_text`, `embedding` vector) with a **tenant global scope** on every query and database-level `NOT NULL` on `owner` and `tenant` (assertion 2).
- **RLS on a shared Postgres:** the global scope is defence in depth; the control is an RLS policy on `elements` reading a session variable the connection sets per request (Supabase's `app.current_user_id` shape) — "RLS is always applied even as new queries and application logic is introduced" (assertion 8); migrations enable RLS and create the policy; a test with two tenants and overlapping content runs with `RefreshDatabase`.
- **Vector column:** `pgvector/pgvector` on Packagist (https://packagist.org/packages/pgvector/pgvector; repository pgvector-php) for the embedding column; the similarity query is the same whether RLS filters it or not.
- **PII scrub:** a Presidio analyzer service over HTTP (https://github.com/microsoft/presidio exposes analyzer and anonymizer as services) called by the job before any insert, with the checksum and regex tier in a PHP validation rule class run first; placeholders written into the element text, the mapping into an encrypted table in a separate schema or the secrets manager, never the `elements` table (assertion 6, 9).
- **Idempotent upsert:** `upsert()` on `(tenant, source_id)` comparing `document_hash`; equal → no write; different → delete the document's elements and insert the new ones in one transaction; a document missing from the corpus walk → a tombstone row with the reason (assertion 5).
- **Audit report:** an Artisan command that walks the corpus, writes `storage/audit/<corpus>.json` with the report fields and the parser version read from the sidecar's health endpoint; the ingestion job refuses to run when the report is missing, stale or lists sources without owner (assertion 1).
- **Erasure:** one job per request that deletes elements by subject, flushes the cache tags for the subject, removes the subject's cases from the eval dataset table and redacts the activity log (`spatie/laravel-activitylog`, https://packagist.org/packages/spatie/laravel-activitylog, if in use), then asserts zero in each by tag and by a content scan, records `erased_at` against the policy deadline and writes the DSAR reference (assertion 7).
- **Pitfall:** a tenant filter that lives only in the global scope — `withoutGlobalScope` in one report query is the `WHERE`-only negative of assertion 8; RLS is what makes it fail safe.
- **Pitfall:** the sidecar upgraded in its container image with the report never regenerated — compare the sidecar's reported version with the report's on every job start.
