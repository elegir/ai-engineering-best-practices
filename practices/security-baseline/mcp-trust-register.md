Rules: default to read-only roles; separate credentials per environment; no server may reach production write paths from an agent session without a human-run step; anything not in this table is removed from the agent's config. **Review the full tool descriptions, not the one-line summary the client shows**: the human approves a summary while the model reads the whole description, which can carry hidden instructions — the "iceberg effect" (Carpintero, 2026-04; `../../sources/2026-10-01-s04-structured-outputs-digest.md` §3.3); re-review when a server updates its tools. **Two columns added 2026-10-01 (s5):** the *identity the tool runs as* and its *credential lifetime* — non-human identities controlled like human users, vault-issued and short-lived where possible (IBM 2026-02); one narrower identity per spawned sub-agent is this KB's extension (opinion) — and *admitted by review on <date>; destructive annotations honoured* — a server enters the list only after a security review and the client honours a tool's destructive annotation with a mandatory approval (Block, Jones 2026-01; `../memory-and-permissions/permission-model.md`).
